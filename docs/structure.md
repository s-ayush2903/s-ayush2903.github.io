# Structure

```
s-ayush2903.github.io/
├── src/
│   ├── content/blog/     ← markdown posts go here
│   ├── pages/            ← routes (index, blog/index, blog/[slug], rss.xml)
│   ├── layouts/          ← Layout.astro (OG tags, fonts, theme bootstrap)
│   ├── components/       ← React islands + shared UI
│   ├── lib/              ← pure utilities (blog.ts, dates.ts, utils.ts)
│   ├── plugins/          ← remark plugin for :::callouts
│   └── index.css         ← Tailwind + CSS custom properties for all 5 themes
├── public/
│   ├── fonts/            ← self-hosted WOFF2 (IBM Plex Sans + Mono)
│   └── og.png            ← social preview (generated by scripts/gen-og-png.mjs)
├── e2e/                  ← Playwright tests (smoke, theme, mermaid)
├── scripts/              ← build-time tooling (copy-fonts, gen-og-png, test-preview)
├── .github/workflows/
│   ├── ci.yml            ← runs on PRs
│   └── deploy.yml        ← runs on master merge → GitHub Pages
├── agents.md             ← project north star (read this before touching anything)
├── architecture.md       ← this doc index
├── astro.config.mjs
├── tailwind.config.ts
├── vitest.config.ts
└── playwright.config.ts
```

## What goes where

| You want to… | Touch this |
|---|---|
| Write a blog post | `src/content/blog/your-slug.md` |
| Add a new page/route | `src/pages/` |
| Change the layout or OG tags | `src/layouts/Layout.astro` |
| Add a UI component | `src/components/` |
| Add a utility function | `src/lib/` |
| Change global styles or a theme color | `src/index.css` |
| Add a markdown extension | `src/plugins/` |
| Add a static asset (image, font) | `public/` |
| Change CI behavior | `.github/workflows/` |
| Change build or deploy config | `astro.config.mjs` / `vercel.json` |

The north star for *why* decisions were made: [agents.md](../agents.md).
