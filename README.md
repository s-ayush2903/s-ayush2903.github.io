## Stack

React · TypeScript · Vite · Tailwind CSS · shadcn/ui · React Router · react-markdown · Vitest

## Dev

```sh
npm install
npm run dev        # localhost:8080
npm run build      # production build
npm run test       # run tests
npm run test:coverage  # coverage report
```
